# YottaWeave

Windows 桌面应用：把编码智能体需要的纪律做成产品能力 —— 跨会话记忆、任务编排、证据校验、权限边界。

安装包见 [Releases](../../releases)。本仓库只分发安装包，不含源码。

## 工作方式

**编排**：任务拆解后按依赖串行或并行派发子代理，主代理负责判断与收口。

**记忆**：按 FACT / PREF / BOUND / COMMIT 四类保存，开工恢复上下文，收工写入；记忆库是普通文件，可 diff、可回滚。

**证据**：结论附命令输出、测试结果、哈希或截图，并按「已验证 / 未验证 / 无法验证」标注。

**边界**：权限、作用域、网络出口由代码判定，不依赖模型自行约束。

---

## 权限

- **项目内**：读写自由。
- **项目外**：弹条审批，弹条中写明触发原因（例如「凭据文件：不读取密钥与令牌」）；选择「总是允许」只对该来源生效。
- **完全访问**：切换后不再询问。
- **始终拒绝**：`rm -rf /`、`mkfs`、`dd of=/dev/*`、`shutdown`、反弹 shell，以及云元数据地址 `169.254.169.254`。
- **网络**：接口调用与 shell 中的 `curl` / `wget` / `ssh` 使用同一套判定；私有网段（`10/8`、`172.16–31`、`192.168/16`）需审批。

## 安装

1. 到 [Releases](../../releases) 下载最新的 `yottaweave-desktop-*-win-x64.exe`。
2. 双击安装，选「仅为我安装」（per-user），无需管理员权限。
3. 打开应用，首次启动会初始化配置与技能。

校验安装包：

```powershell
Get-FileHash .\yottaweave-desktop-<版本>-win-x64.exe -Algorithm SHA256
```

每个 Release 都写明文件大小与 SHA-256。安装后可核对版本：

```powershell
& "$env:LOCALAPPDATA\Programs\YottaWeave\resources\yottaweave-cli.exe" --version
```

## 数据位置

| 内容 | 路径 |
| --- | --- |
| 用户数据（会话、记忆、配置） | `%USERPROFILE%\.yottaweave` |
| 应用日志 | `%APPDATA%\com.yottaweave.desktop\logs` |
| 安装目录 | `%LOCALAPPDATA%\Programs\YottaWeave` |

覆盖安装保留配置与记忆。需要干净重建时删除 `%USERPROFILE%\.yottaweave\config`，记忆库不受影响。卸载不删除会话数据。

---

## 已知限制

- 配置目录的内容保护只覆盖编辑类工具，通过 shell 写入不经过审批。
- 权限规则按装配时的路径判定，通过软链或 junction 访问同一目录时可能不命中。
- shell 网络识别覆盖有限：变量拼接、命令替换、base64、脚本内部发起的请求无法识别。
